Privacy Policy

Last updated: 18 November 2026

Clip Engine Studio ("the App") is a desktop tool that runs on its operator's own computer. This policy explains what data it handles.

Data the App accesses

  • TikTok: basic profile information (open ID, display name, avatar) via user.info.basic, and permission to upload and publish videos via video.upload and video.publish.
  • YouTube: permission to upload videos via the youtube.upload scope.

How the data is used

This access is used only to publish clips created by the App to the operator's own accounts and to confirm that uploads succeeded. Profile information is used only to show which account is connected.

Storage

Access tokens are stored only on the operator's computer. No data is sent to any server other than TikTok's and Google's own APIs. The App has no database of users and does not collect data about viewers or other accounts.

Sharing

No data is sold, shared or transferred to third parties. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Revoke access from TikTok (Settings → Security → Manage app permissions) or your Google Account (Security → Third-party access). Deleting the App's tokens folder removes all stored credentials.
